# Cómo elegir un acondicionador de armario para envolventes industriales

Guía práctica de selección para cuadros eléctricos, telecom, baterías y cabinas.

Cuando la ambiente supera ~40°C, el ventilador no basta. El **circuito cerrado** (compresor, IP55) mantiene 25–35°C y excluye polvo/humedad.

## Dimensionado
- Pequeño (<2 m3): **3000 W**
- Mediano (2–4 m3): **5000 W**
- Grande/contenedor (>4 m3): **7500 W**

## Qué importa
- IP55 para exterior e industria
- Funciona **de -40°C a +55°C**
- R410A + microcanal (~30% más eficiente)
- RS485/Modbus remoto
- desde 52 dB, sin herramientas
